# Security policy

secondbrain-skills is a set of Markdown instructions plus a few small helper scripts that agents run against a local Obsidian vault. The things worth reporting are ones that could make an agent leak, overwrite or delete vault content it was not authorized to touch, run an unexpected command, or exfiltrate data.

## Supported versions

Only the latest release on `main` receives fixes. This is a prerelease project.

## Reporting a vulnerability

Please report privately through [GitHub private vulnerability reporting](https://github.com/GoBeromsu/secondbrain-skills/security/advisories/new), or by email to [gobeumsu@gmail.com](mailto:gobeumsu@gmail.com). Do not open a public issue.

Include the package, the prompt or input that triggers the behaviour, what happened, and what you expected. You should hear back within a week. Once a fix is released the advisory will credit you unless you ask otherwise.
