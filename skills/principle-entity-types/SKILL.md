# Entity types

The type decides the template and the folder, so it is settled before an Entity page is written.

- Type a named individual by what it is: person, organization, place, paper, book, media (a publisher that keeps putting things out), product, or an optional type for any other named individual.
- One video, episode, issue or post is a Raw source, not an Entity; the media Entity that published it lists it.
- An update never moves or retypes an Entity.
- A folder for a new optional type needs the owner's approval.

The type table and folder steps are in `entity` Step 1. The vault's live policy overrides any line here. This principle shapes a write the task already asked for; it is not a reason to make one, and not a reason to withhold one.
