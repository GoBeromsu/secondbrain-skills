# Original order

The relationships between the parts of a source are evidence, so the creator's own sequence, headings and wording survive capture.

- Preserve the creator's sequence, headings and wording; leave an unknown order unknown rather than inventing one.
- Keep compilation and annotation apart from the original text.
- Leave an existing Raw capture's body unchanged: append new evidence after it, and save a fuller or improved extraction as a new linked Raw capture.
- Compare preserved text against the version that was reviewed, not against guessed heading boundaries.
- Record conversion limitations next to the captured text, not inside it.

Example: a three-message public discussion keeps its sequence and attributions, and a Concept page synthesizes it without rewriting the Raw capture.

The vault's live policy overrides any line here. This principle shapes how a capture the task asked for is made; it is not a reason to write, move or delete anything.
