# The TL;DR is plain text

The TL;DR is read first and often alone, and wikilinks, URLs and footnote markers break it up for the eye.

- Write it as sentences with at most one bold phrase.
- Name a note or product in plain words there; the sections below carry the links and footnotes for the same claims.

The vault's live policy overrides any line here. This principle shapes a write the task already asked for; it is not a reason to make one, and not a reason to withhold one.
